## 🛠️ Funcionalidades do Sistema

### **Requisitos Obrigatórios (Back-end - Python)**

- **[X] POST /products:** Endpoint para inserção manual de novos produtos.
- **[X] POST /products/csv:** Endpoint para importação de produtos via arquivo CSV.
- **[X] GET /products:** Listagem de produtos, incluindo dados de vendas e lucro.
- **[X] GET /categories:** Listagem das categorias cadastradas no sistema.
- **[X] Database:** Persistência de dados em banco de dados (Relacional ou em memória).

### **Requisitos Obrigatórios (Front-end - React)**

- **[ ] Dashboard:** Mínimo de dois gráficos (Quantidade de Vendas e Lucro das Vendas).
- **[ ] Formulário de Cadastro:** Interface para registro manual de novos produtos.
- **[ ] Importação CSV:** Funcionalidade de upload de arquivo para inserção em massa.
- **[X] Filtros:** Sistema de busca/filtro de produtos por categoria.
- **[X] UI/UX:** Interface estilizada obrigatoriamente com **Tailwind CSS** e componentes (Shadcn/UI ou Ant Design).

### **Funcionalidades Extras (Implementadas)**

- **[ ] Edição de Valores:** Possibilidade de editar número de vendas e preços para cada mês do ano.
- **[X] Gestão de Categorias:** Inserção de novas categorias via interface.
- **[X] Exportação:** Download de arquivo CSV baseado nos dados atuais do banco de dados.
